# Inside M6 · 中文交互教学

用户要求：使用 Three.js 展示 M6 CPU 原理、模块通信与最大 4.8 GHz 的含义，仅在本机运行。

实现选择：Vite + 原生 JavaScript + Three.js；深色、青绿/紫色的实验室视觉。一个页面、三个章节，共享可旋转的 3D 场景。模块可点击并有等价按钮；通信实验支持缓存命中、内存读取和 CPU/GPU 共享数据；时钟实验支持频率与 IPC 滑块、暂停和步进。

考虑过静态长文、独立 3D 沙盒和引导式实验。采用引导式实验，兼顾初学者解释与自主操作。这是实现选择，不是用户指定的视觉设计。

公开规格来自 Apple 2026-08-25 M6 新闻稿：12 核 CPU（2 超级/4 性能/6 能效）、12 核 GPU、双 16 核 Neural Engine。物理布局、缓存层级连接、延迟和动画时序为通用原理示意，不声称复刻 M6 微架构。4.8 GHz 作为用户提供的频率示例，官方新闻稿未给出该频率，不将其标成官方保证。显示最大频率不代表所有核心始终运行在该频率。

验收：可用的本机地址；无需运行时 CDN；鼠标/触摸旋转、缩放、重置；模块说明；三种真实不同的数据路径；GHz/周期/IPC 换算正确；小屏无溢出；WebGL 失败仍可阅读；减少动态效果；来源说明。
