# Inside M6 Implementation Plan

Goal: 本机运行的 Three.js 中文 CPU 教学页面。
Architecture: 静态 UI 与单个 WebGL 场景共享章节和实验状态；独立纯函数负责频率计算和通信步骤。
Tech Stack: Vite, Three.js, JavaScript, Node test runner.
Spec: docs/superpowers/specs/2026-11-03-m6-design.md

## Constraints
仅绑定 127.0.0.1；不发布；依赖打包本地；不读取系统监控；教学假设明确标注。

## Tasks
- [x] 1. tests/model.test.js 先验证 GHz 转换、IPC 吞吐、缓存命中/未命中不同路径、GPU 同步步骤，再实现 src/model.js。
- [x] 2. index.html、src/main.js、src/style.css 构建三个章节、模块说明、控制器、来源和键盘入口。
- [x] 3. src/scene.js 构建芯片模块、连线、数据包、点击拾取、旋转和重置，以及 WebGL 降级。
- [x] 4. 运行 npm test 和 npm run build；浏览器验证桌面/手机、切换、滑块、暂停步进、模块选择、无控制台错误；启动本地地址交付。

## Review focus
1. GHz 与每秒指令混淆，频率端点/非有限输入。
2. 请求与响应方向；缓存命中不能访问 DRAM；GPU 必须在同步后读取。
3. 切换章节与暂停/单步状态一致，频率变化不暗示总线同步加速。
4. 小屏可阅读操作；无 WebGL 不阻断正文。
5. 动画说明明确、非物理比例，不引用未公开缓存大小与延迟。

## Verification record
- 7 个 Node 测试通过；Vite 生产构建通过。Three.js 单包约 598 KB（gzip 155 KB），触发默认体积提示；本机静态使用可接受。
- Playwright + 独立无头 Chrome 检查桌面、390px 手机、850px 导航、模块选择、通信场景、时钟换算与单步、弹窗、放大/重置；无页面脚本错误。
- 额外验证减少动态效果时暂停切换通信章节立即初始化、WebGL 不可用时文字与时钟实验仍可使用。
- 独立审查发现并修复：通信章节初始化顺序、单步与自动时钟坐标不一致、窄屏导航可访问名称缺失。另修复游标回绕导致的时钟相位不一致。
- 无既有 Git 仓库；直接在用户给定空目录实现，没有创建额外工作树或发布远程站点。
