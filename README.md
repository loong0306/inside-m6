# Inside M6 · 芯片原理交互实验室

本机运行的中文 Three.js 页面：旋转与点选芯片模块、逐步跟随数据通信、调节频率和 IPC，理解 4.8 GHz。

## 运行

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173 。服务仅绑定本机，不发布到互联网。依赖全部由本地构建提供，页面不依赖运行时 CDN。

## 交互

- **认识芯片**：拖动旋转、滚轮/双指缩放、点击模块或使用下方按钮，右上角可重置/放大模型。
- **通信实验**：缓存命中、缓存未命中、CPU/GPU 共享数据。可播放、暂停、选择步骤或单步前进。
- **时钟实验**：0.8–4.8 GHz 与假设 IPC 滑块，实时显示周期与理论吞吐量；单步观察一个周期。
- 自动遵循系统“减少动态效果”；不支持 WebGL 时仍可阅读说明、使用实验控件。
- 侧栏“关于模型与资料”提供来源和示意边界。

## 内容边界

M6 核心数量与分类依据 [Apple 官方介绍](https://www.apple.com/newsroom/2026/08/apple-introduces-m6-and-m5-ultra-for-a-big-leap-in-performance-and-ai-compute/)。模块布局、缓存层级和通信线路是教学抽象，不是物理裸片复刻。4.8 GHz 是本实验采用的频率示例，所引 Apple 官方介绍未公布该频率；不表示官方保证、本机实测或全核持续运行频率。

4.8 GHz = 每秒 48 亿时钟周期，周期约 0.208 ns。每秒指令数还取决于平均 IPC；实验中的 IPC 为假设值。时钟放慢十亿倍，通信步骤使用独立教学时间；调节频率不会修改真实硬件。
